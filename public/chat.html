Contribute computing to KENUXA

This is optional and off until you start it. If you start it, this tab checks small batches of public KENUXA knowledge atoms: structure, links and integrity. It runs in a background worker, and only while this tab is open and visible.

It never receives conversations, accounts, passwords or private knowledge, and it runs no code other than KENUXA's fixed, published task list (view it). The node double-checks every result, so a wrong result cannot change KENUXA's knowledge. You can stop at any time; using KENUXA never requires this.

Browsers don't let pages read CPU temperature or set an exact CPU share. Limits are enforced through task size, pace, hourly caps and pausing in the background or on low battery (where the browser reports it).

To speed things up, this tab may keep atoms it has already checked in a small temporary cache, so another volunteer can fetch them from you directly (peer-to-peer) instead of from the server. Every atom received that way is checked against its fingerprint. Joining also solves a small puzzle that stops automated mass sign-ups.
